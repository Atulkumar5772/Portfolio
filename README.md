# Atul Kumar — Systems & Backend Engineering Portfolio

A modern, high-performance portfolio engineered with React, Three.js, WebGL2, and Tailwind CSS. Showcasing low-level kernel watcher daemons, zero-knowledge cryptographic vaults, high-concurrency reservation engines, and aerospace digital twins.

## Tech Stack
- **Frontend Framework:** React 18, Vite
- **Graphics & Visuals:** Three.js, WebGL2 shaders, GSAP
- **Styling:** Tailwind CSS, custom glassmorphism
- **Icons:** Lucide Icons, Custom SVGs

## Featured Projects
- **Phoenix-Linux:** Real-time kernel watcher and file integrity self-healing daemon.
- **ZeroTrace-Vault:** Zero-knowledge client-side ephemeral secret orchestration vault.
- **Flash-Seat:** High-concurrency ticket reservation engine with InnoDB row locking.
- **Garuda Aero GCS:** Autonomous drone ground control station and DGCA geofence digital twin.
- **DeliveryFence:** Geospatial doorstep anti-fraud forensics platform.

## Development Setup

```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Create optimized production build
npm run build
```
